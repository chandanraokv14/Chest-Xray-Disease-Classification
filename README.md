# 🩻 Chest X-Ray Disease Classification

An educational deep learning project for classifying selected abnormalities in chest X-ray images using a pretrained **DenseNet121** model.

> ⚠️ **Educational Use Only:** This project is intended for educational and research purposes. The predictions generated by this model must **not** be considered medical diagnoses or used for clinical decision-making.

---

## 📌 Project Overview

This project explores the use of deep learning and computer vision for automatic classification of selected abnormalities in chest X-ray images.

A pretrained **DenseNet121** convolutional neural network was fine-tuned to classify three target abnormalities:

* Atelectasis
* Effusion
* Pneumonia

The project includes model training, validation, testing, classification metrics, ROC-AUC analysis, confusion matrices, and Grad-CAM visualization.

---

## 🎯 Problem Statement

Develop an AI system that analyzes chest X-ray images and predicts selected abnormalities or diseases.

The system is designed to provide:

* Input chest X-ray image
* Predicted abnormality
* Confidence score
* Classification metrics
* ROC curves
* Confusion matrices
* Grad-CAM visualization

---

## 🗂️ Dataset

The project uses the **NIH Chest X-ray dataset (ChestX-ray14)**.

The original dataset contains chest X-ray images associated with multiple findings. For this project, a subset containing at least one of the selected target abnormalities was used.

### Selected abnormalities

| Abnormality | Description                                     |
| ----------- | ----------------------------------------------- |
| Atelectasis | Partial or complete collapse of lung tissue     |
| Effusion    | Abnormal accumulation of fluid around the lungs |
| Pneumonia   | Infection-related lung abnormality              |

### Dataset statistics

| Description             | Count |
| ----------------------- | ----: |
| Original images indexed | 5,606 |
| Target-disease images   | 1,047 |
| Unique patients         |   874 |
| Target classes          |     3 |

The dataset itself is **not included in this repository** because of its large size.

---

## 🔐 Patient-Level Data Split

To reduce the possibility of data leakage, the dataset was split at the **patient level** rather than randomly splitting individual images.

| Dataset    |    Images |
| ---------- | --------: |
| Training   |       730 |
| Validation |       168 |
| Testing    |       149 |
| **Total**  | **1,047** |

Training, validation, and testing images were assigned using separate patient groups.

## 🧠 Model

### DenseNet121

The primary model used in this project is **DenseNet121**, a convolutional neural network pretrained on ImageNet.

The final classification layer was adapted for the three target abnormalities.

### Why DenseNet121?

DenseNet uses dense connections between layers, allowing information and gradients to flow efficiently through the network.

It is also commonly used as a baseline architecture for medical image classification research.

## 📊 Final Test Results

The final model was evaluated using the held-out test dataset.

| Disease     | Accuracy | Precision | Recall | F1 Score | ROC-AUC |
| ----------- | -------: | --------: | -----: | -------: | ------: |
| Atelectasis |   0.6510 |    0.6386 | 0.7067 |   0.6709 |  0.6813 |
| Effusion    |   0.6913 |    0.7792 | 0.6742 |   0.7229 |  0.7127 |
| Pneumonia   |   0.8322 |    0.1250 | 0.4286 |   0.1935 |  0.7274 |

### Interpretation

The model achieved the highest F1 score for **Effusion** among the three classes.

Pneumonia achieved relatively high accuracy, but its precision and F1 score were considerably lower. This is consistent with the small number of Pneumonia-positive samples in the dataset.

Therefore, **accuracy alone should not be used to evaluate this model**.

## ⚠️ Limitations

This project has several limitations:

1. Only three abnormalities were selected.
2. The model was trained using a subset of the available dataset.
3. The classes are imbalanced, particularly Pneumonia.
4. The model has not undergone clinical validation.
5. Performance may differ on external datasets.
6. The dataset may contain labeling limitations.
7. High accuracy does not necessarily indicate good clinical performance.
8. Grad-CAM provides an interpretability aid but does not establish medical correctness.
9. The model is not intended for real-world clinical diagnosis.
